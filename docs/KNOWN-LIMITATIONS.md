# Souliography — Known Limitations & Methodology Disclosures

## 1. Non-Latin Name Scripts
Pythagorean name numerology is calibrated for the Latin alphabet. Non-Latin scripts (Arabic, Cyrillic, Devanagari, Chinese, Japanese) are handled gracefully via diacritic normalization or trigger explicit methodology notices asking the user to enter their Latin transliterated name for Pythagorean calculations.

## 2. Esoteric & Self-Reflection Framing
Destiny Matrix chart readings and 7 Chakra energy tables are mathematically deterministic according to Natalia Ladini's 2000s framework, but are framed strictly as non-dogmatic self-reflection tools, not medical, legal, or psychological diagnoses.

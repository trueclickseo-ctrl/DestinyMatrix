- **Convention**: Period Reduction (Month, Day, and Year reduced independently before summing).

## 2. Destiny Matrix (Matrix of Destiny)
- **System**: Natalia Ladini 22 Arcana System (mid-2000s).
- **Convention**: `val > 22 => sum individual digits until 1 <= val <= 22`.
- **Node Formulas**:
  - Day Node (Position A): Day reduced to 1–22.
  - Month Node (Position B): Month (1–12).
  - Year Node (Position C): Birth year digits sum reduced to 1–22.
  - Bottom Node (Position D): A + B + C (reduced to 1–22).
  - Center Node (Position E): A + B + C + D (reduced to 1–22).
- **Status**: `VERIFIED WITH METHODOLOGY NOTE`.

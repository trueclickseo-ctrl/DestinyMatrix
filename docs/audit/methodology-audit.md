## 2. Reduction Rules & Conventions

### Destiny Matrix 22 Arcana Rule
- If $val > 22$, digits are summed until $1 \le val \le 22$.
- Example: $29 \rightarrow 2+9 = 11$. $31 \rightarrow 3+1 = 4$.

### Pythagorean Life Path Period Reduction Rule
- Month reduced to single digit or 11.
- Day reduced to single digit or 11, 22.
- Year digits summed and reduced to single digit or 11, 22.
- Total = Month + Day + Year, reduced to single digit ($1\dots9$) or Master Number ($11, 22, 33$).

### Name Numerology Character Mapping Rule
- Pythagorean English mapping ($A=1 \dots Z=8$).
- Vowel rule: $A, E, I, O, U$, plus $Y$ when acting as primary vowel sound.
- Explicit non-Latin character disclosure note.

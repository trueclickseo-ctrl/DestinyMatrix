# Design Audit

## 1. Existing Visual Identity Breakdown
- **Current Style**: Generic modern purple/pink AI SaaS aesthetic (`from-violet-950 via-purple-900 to-indigo-950`), glowing text, `rounded-3xl` cards, floating dashboard elements.
- **Font Stack**: Google Fonts (`Amiri`, `Inter`, `Outfit`). `Outfit` gives a modern startup feel that clashes with reference library aesthetics.

## 2. Target Design Language ("Digital Occult Reference Library")
- **Concept**: 2000–2005 internet personality combined with 2026 usability and accessibility.
- **Color Palette**:
  - Parchment content background: `#FBF9F5` / `#F6F3EB`
  - Deep ink typography: `#1C1625`
  - Deep violet/burgundy header & nav: `#231530`
  - Muted antique gold accents: `#C4A052`
  - Thin subtle borders: `#D8D0C5`
- **Typography Stack**:
  - Headings: `Playfair Display`, `Cinzel`, `EB Garamond`
  - Body & UI: `Inter` / system sans-serif font
- **UI Components & Elements**:
  - Thin double-line borders (`border-double`)
  - Compact reference frames and data blocks
  - Retro-styled buttons (`btn-retro`)
  - Subtle paper texture overlay
  - Classical reference book section dividers
  - High contrast accessibility

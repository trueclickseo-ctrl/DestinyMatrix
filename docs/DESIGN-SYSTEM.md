# Souliography — Design System Specifications ("Digital Occult Reference Library")

## 1. Design Direction
Modernized Early-2000s Digital Occult Reference Library aesthetic replacing generic AI SaaS purple-pink gradients and floating cards.

## 2. Color Palette Tokens
- **Parchment Background**: `--color-parchment: #FBF9F5`
- **Parchment Subtle**: `--color-parchment-subtle: #F5F2EB`
- **Deep Ink**: `--color-ink: #1C1625`
- **Deep Ink Muted**: `--color-ink-muted: #524B5A`
- **Deep Nav Violet**: `--color-nav-violet: #231530`
- **Antique Gold Accent**: `--color-accent-gold: #C4A052`
- **Subtle Border**: `--color-border-subtle: #D8D0C5`

## 3. Typography Stack
- **Headings**: Classical Serifs (`Playfair Display`, `Cinzel`, `EB Garamond`).
- **Body**: Clean System Sans (`Inter`).
- **Arabic Script**: Classical Serif (`Amiri`).

## 4. Reusable Reference Components
- `CalculationBreakdown.astro`
- `MethodologyBox.astro`
- `DisclaimerBox.astro`
- `Breadcrumbs.astro`
